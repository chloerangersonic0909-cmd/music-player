# Moonwave — Music Player

เว็บไซต์เครื่องเล่นเพลงธีมดำ ม่วง และฟ้า ออกแบบสำหรับมือถือ

## Features
- ฝัง YouTube Player ภายในหน้าเว็บ
- เพลงแนะนำและช่องวาง YouTube URL / video ID
- ปุ่มควบคุมพื้นฐานและ responsive layout
- ไม่ต้องใช้ API key หรือ backend

## Run locally
เปิด `index.html` ในเบราว์เซอร์ หรือใช้ static hosting เช่น GitHub Pages

## Notes
- การเล่นเสียงอาจต้องให้ผู้ใช้แตะปุ่มเล่นก่อน เนื่องจากข้อจำกัด autoplay ของเบราว์เซอร์
- เนื้อหาและโฆษณาของ YouTube อยู่ภายใต้เงื่อนไขของ YouTube
